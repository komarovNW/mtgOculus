# Маршруты Magic Oculus

Документ описывает текущие пользовательские страницы. Все маршруты сейчас
открываются без авторизации.

## Публичные страницы

| Маршрут | Что показывает |
|---|---|
| `/` | Общие показатели, метагейм, результативность колод, игроков, матчапы и последние события |
| `/digest` | Заглушка будущих ежемесячных статей по статистике |
| `/changelog` | Текущая версия и история пользовательских изменений |
| `/dailies` | Только события с `tournamentType=daily` |
| `/tournaments` | Только события с `tournamentType=tournament` |
| `/tournaments/:id` | Стендинги, раунды, колоды и метагейм события |
| `/players` | Поиск, сортировка и дозагрузка списка игроков |
| `/players/:id` | Статистика, события, колоды и матчи игрока |
| `/decks` | Поиск, сортировка и дозагрузка всех колод |
| `/decks/:id` | Статистика, результаты, игроки и матчапы колоды |

### Дайджест

`/digest` зарезервирован под ежемесячные редакционные статьи с выводами по
статистике прошедшего месяца.

Текущее состояние:

- показывается статический placeholder `В разработке`;
- ссылка на экран скрыта из основной навигации;
- нет списка и detail-страниц статей;
- нет CMS, API и запросов к backend;
- dashboard-фильтры не добавляются в URL при переходе в раздел.

### Что нового

`/changelog` — вспомогательная страница истории версий. Она не занимает место в
основной навигации: ссылка с текущей версией находится в футере.

- `0.2.1` показана как текущий релиз;
- `0.2.0` содержит большое обновление статистики и интерфейса;
- `0.1.0` показана как первый публичный релиз;
- dashboard-фильтры на страницу не переносятся.

### Фильтры статистики

Статистические страницы используют общие фильтры:

- город;
- клуб;
- формат;
- тип события;
- дата от и дата до.

На `/dailies` и `/tournaments` тип события задан самим маршрутом, поэтому
соответствующий select скрыт. Выбранный срез сохраняется в query string при
переходе между статистическими разделами.

Дайджест не использует эти фильтры.

По умолчанию используются:

```text
cityId=moscow
formatId=legacy
```

## Технические маршруты

- `/home` перенаправляет на `/`;
- `/login` удалён и показывает 404;
- неизвестный путь показывает `NotFoundPage`.

## Добавление события

`/admin/tournaments/create` — публичная форма добавления дейлика или турнира.
Авторизация не требуется.

Форма принимает дату, город, клуб, тип, формат, ссылку Aetherhub и список
игроков с колодами.

## Навигация

В основной шапке всегда видны:

- `Главная`;
- `Дейлики`;
- `Турниры`;
- `Игроки`;
- `Колоды`;
- `Добавить`;
- переключатель светлой и тёмной темы.

На ширине до 760 px ссылки открываются через мобильное меню.

В футере находится ссылка `v0.2.1 · Что нового`.

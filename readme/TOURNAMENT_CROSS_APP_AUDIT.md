## Правила интерпретации

- `rank` — итоговое место. `swissRank` — только справочное место после швейцарки.
- Топ-4 и топ-8 в достижениях означают итоговое место ≤4 и ≤8, включая победы. Это вложенные показатели, а не число выходов в плей-офф. Они применяются и к турнирам без топа; пояснение видно в интерфейсе.
- Дейлики исключены из турнирных достижений. Повтор одного события не удваивает достижения. Неизвестное/нулевое место не становится победой.
- Лучшее выступление: наименьшее место, затем большее поле, затем более свежая дата.
- `playoffSize: null` означает отсутствие топа. Отсутствующее поле означает отсутствие сведений — фронт не утверждает, что плей-офф не было.
- Краткие ответы игрока/колоды в текущем Swagger не гарантируют swissRank и playoffSize. Поддержка этих полей необязательна; подробности игрока загружаются из существующей детали турнира по раскрытию строки. Массовой загрузки всех турниров ради этого нет.
- На детали турнира ссылки на сущности получают реальный формат/город/клуб/тип турнира, включая вход по прямому URL без фильтров.
- Переход на отдельные списки дейликов/турниров очищает конфликтующий тип события; сами страницы фиксируют тип API-запроса.

## Проверка

Автоматические сценарии покрывают достижения, исключение дейликов/дубликатов, неизвестные места, топ-4/топ-8/без топа/неизвестный топ, раскрытие выступления, финал со счётом 2-1-1, фильтры ссылок. Существующие тесты покрывают большой турнир на 109 игроков, BYE, неизвестного соперника, импорт, матчапы, профиль и колоды.

Ограничение ручной проверки: реальный API при открытии профиля в браузере не завершил загрузку; это не подтверждение работы новой версии бэка. Новый контракт лиг проверен тестовыми ответами, а не продом.

# Зафиксированные решения по проверенным экранам

Состояние на **16 сентября 2026 года**. Этот документ фиксирует уже принятые
продуктовые решения, чтобы не начинать повторный аудит тех же экранов без новой
причины.

Повторно открываем решение только если:

- найден воспроизводимый баг;
- изменился контракт API или смысл показателя;
- появились новые реальные данные;
- пользователь явно просит изменить принятое решение.

## Общие правила

- Backend — источник истины для агрегатов, record, winrate, BYE и признака малой
  выборки.
- Клиентская сортировка помечается как сортировка только загруженных строк.
- Предупреждение о частичном списке находится вне горизонтального скролла и не
  ломает мобильную вёрстку.
- Таблицы не должны выводить колонку, смысл которой теряется без обязательного
  фильтра.
- Число предпочтительнее декоративной шкалы, если шкала не добавляет контекст.
- На мобильном экране допустим горизонтальный скролл сложной таблицы, но текст,
  фильтры и действия должны оставаться в ширине экрана.
- Во всех таблицах названия и текстовые поля выравниваются слева, а места,
  количества, проценты, результаты и действия — по центру. Заголовок и данные
  колонки используют одинаковое выравнивание; строки центрируются по вертикали.

## Общие тексты

Финальный редакторский проход выполнен 17 сентября 2026 года.

- Публичные тексты не объясняют устройство API, backend или пагинации.
- В подписях используется «Процент побед»; «винрейт» убран из обычного
  интерфейса.
- Вместо «достаточной выборки» объясняется, достаточно ли матчей для сравнения.
- Пояснения профилей, матрицы и лиги сокращены до информации, необходимой для
  чтения показателя.
- Инструкция добавления события сведена к трём шагам; форматы списка оставлены
  в раскрываемой справке.
- История версий описывает пользовательские изменения без технических деталей.

## Главная

Экран считается проверенным.

- Без выбранных фильтров остаются только общая сводка и последние события.
- Аналитика колод и матчапов показывается только при выбранном формате.
- «Игроки с лучшими результатами» — топ-10, только на достаточной выборке.
- Полосы у доли меты и процента побед удалены: остаются точные значения.
- Колонки и кнопки выровнены; повторяющиеся и слабые обзорные блоки убраны.
- Не возвращаем метрики, которые лишь пересказывают соседнюю таблицу.

## Дейлики

Экран считается проверенным.

- Без фильтров не показывается общая аналитика, смысл которой смешивает города,
  клубы и форматы.
- При выбранном срезе остаются средняя посещаемость, рекорд посещаемости,
  динамика и самый активный клуб.
- «Обычные дни проведения» не добавляем.
- Клуб и формат скрываются из таблицы, когда уже заданы фильтром.
- Колонки с техническими подробностями списка сокращены.

## Игроки

Экран списка считается проверенным.

- Основная задача экрана — найти игрока и быстро оценить объём и результат его
  выступлений.
- Оставлены турниры, сыгранные матчи, record, процент побед и любимая колода при
  выбранном формате.
- BYE не занимает отдельную строку в списке; подробность остаётся в профиле.
- Удалён «Быстрый ориентир», который повторял первую строку таблицы и требовал
  отдельной загрузки всех игроков.
- Любимая колода скрывается без выбранного формата.
- Поддержаны серверные поля `lastTournamentDate` и `undefeatedTopsCount`.
  Первое показывается под именем, второе — отдельной колонкой. Пока production
  API их не возвращает, пустые элементы интерфейса не выводятся.
- `undefeatedTopsCount` означает число турниров, где игрок прошёл все
  запланированные раунды без поражений и ничьих. Досрочно выбывшие игроки не
  учитываются.

## Профиль игрока

Экран считается проверенным.

- Фильтры по умолчанию свёрнуты, чтобы на телефоне статистика игрока попадала
  в первый экран. При необходимости панель раскрывается одной кнопкой.
- В верхней сводке остаются турниры, сыгранные матчи, record и процент побед.
  «Топы без поражений» появляются только когда поле вернул backend.
- Дублирующая карточка с любимой колодой, форматом, частым оппонентом и периодом
  удалена: эти данные уже доступны в соответствующих вкладках.
- График показывает активность по месяцам, а не вычисленный на клиенте
  помесячный winrate. При неполной истории это явно отмечается.
- Для сводки выполняется один запрос профиля с текущими фильтрами. Повторный
  запрос без фильтров и отдельные запросы турниров для пересчёта топов удалены.
- На ширине 390 px нет глобального горизонтального скролла. Вкладки и широкие
  таблицы прокручиваются внутри своих областей; карточки сводки идут в две
  колонки.
- Следующие полезные показатели требуют поддержки backend: текущая форма в
  сравнении с предыдущим равным периодом и игровой record с явным покрытием
  данных. До появления надёжного контракта на клиенте их не считаем.
- Названия событий в сводке, графике, вкладке и таблице меняются вместе с
  фильтром: «дейлики», «турниры» или общие «события».
- Общий процент побед и проценты по колодам берутся из ответа backend. Только
  детализация по оппонентам и матчапам считается из доступной истории и явно
  помечается как неполная, если backend вернул не все матчи.

## Профиль колоды

Экран считается проверенным.

- Фильтры свёрнуты по умолчанию. Формат не предлагается менять: он является
  свойством самой колоды.
- В сводке остаются участия, реальные матчи, record и процент побед. Доля
  метагейма появляется только из `summary.metaShare`, если её вернул backend.
- Загрузка полного каталога колод ради клиентского пересчёта доли меты удалена.
- Обзорный блок сокращён до лучшего и худшего матчапа на достаточной по мнению
  backend выборке. Самый частый матчап не дублируется над таблицей, которая и
  так отсортирована по числу встреч.
- График показывает только число участий по месяцам. Помесячный winrate из
  строковых результатов на клиенте больше не рассчитывается.
- Вкладки с матчапами, турнирами и игроками сохранены. На ширине 390 px вся
  страница остаётся в границах viewport, а таблицы прокручиваются только внутри
  своих карточек.
- Названия событий меняются вместе с фильтром: «дейлики», «турниры» или общее
  «события». Дублирующая число матчей колонка с их долей удалена. Таблицы
  используют серверные `matchWinRate`, `winRate` и `isSmallSample` без
  клиентского пересчёта.
- Для дальнейшего развития backend может вернуть сравнение с предыдущим
  периодом и доверительные интервалы матчапов. До появления контракта frontend
  их не восстанавливает.

## Колоды

Экран списка считается проверенным.

- Основная задача — найти колоду и сравнить её популярность и результат с
  другими колодами выбранного среза.
- Дублирующая «Сводка» удалена. Самая популярная колода уже стоит первой при
  сортировке по популярности, а лучший winrate доступен отдельной сортировкой.
- В обычном режиме загружается только текущая серверная страница. Полный каталог
  больше не скачивается ради обзорных клиентских показателей.
- Production API пока игнорирует `search` и некорректно обрабатывает
  `sort=winRate_desc`, поэтому только эти два режима временно используют полный
  список и клиентскую обработку.
- Формат скрывается из таблицы, если он уже выбран фильтром. Турниры, участия,
  реальные матчи, record и процент побед сохранены как полезные показатели.
- Подписи событий меняются вместе с фильтром: «дейлики», «турниры» или общее
  «события». Серверный `matchWinRate` показывается без пересчёта на frontend.
- На мобильном фильтры свёрнуты по умолчанию, а таблица прокручивается внутри
  карточки. Поиск, сортировка и первые строки списка помещаются значительно
  ближе к началу страницы.
- Метка состояния фильтров «Все данные» заменена на «По умолчанию»: стандартный
  набор уже содержит Москву и Legacy.

## Матрица матчапов

Экран считается проверенным.

- Матрица остаётся главным содержимым: строка — выбранная колода, столбец —
  соперник; ячейка показывает winrate и число матчей.
- Сохраняются серверные общий результат против поля, доля меты, зеркальные
  матчи, признак малой выборки и доверительный интервал в подробностях ячейки.
  Frontend только форматирует эти значения и окрашивает ячейки.
- Фильтры на мобильной ширине свёрнуты, но на десктопе остаются раскрытыми.
  Число колод и быстрый период вынесены в компактный отдельный блок.
- Повторяющий текст периода удалён, пояснения сокращены. Пресеты 30, 90, 180,
  365 дней и «Всё время» сохранены.
- На ширине 390 px документ остаётся шириной 390 px. Матрица имеет внутреннюю
  область 330 px и собственный горизонтальный скролл до полной ширины 1196 px.
- Выбор произвольного набора колод остаётся будущей задачей backend: текущий API
  принимает только `top` и пока не поддерживает рабочий `deckIds`.

## Лиги

Экран считается проверенным.

- Главные данные — официальный рейтинг, турнирные и бонусные очки, число
  зачтённых турниров и расшифровка каждого результата. Все значения берутся из
  ответа backend без клиентского пересчёта.
- Город, клуб, формат, тип события и период на этом экране не фильтруются.
  Пользователь выбирает готовую лигу в одном списке; клуб и формат видны в
  названии варианта. Селектор остаётся на экране даже при одной доступной лиге.
- В официальном порядке выводится одна колонка «Место». Показатели и их подписи
  строятся по `columns` из ответа backend, поэтому набор тай-брейков может
  отличаться у разных лиг.
- Пользовательская сортировка удалена: порядок, места и зоны определяет backend.
  Для `qualify` и `reserve` строки получают подпись и фоновую подсветку, а над
  таблицей показывается легенда с отсечками.
- У каждой лиги есть персональная ссылка `/leagues/:id`; старый query-параметр
  `leagueId` перенаправляется на новый маршрут.
- Правила бонусов и подробности игрока сохранены: они объясняют итоговые очки и
  показывают, какие турниры вошли в зачёт. Раскрытие использует компактные
  строки вместо вложенных карточек, а действие занимает одну иконку. Числовые
  заголовки и значения закреплены в общей сетке колонок. На мобильном широкая
  таблица имеет собственный горизонтальный скролл.

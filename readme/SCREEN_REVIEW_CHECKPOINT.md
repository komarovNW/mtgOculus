# Зафиксированные решения по проверенным экранам

Состояние на **16 сентября 2026 года**. Этот документ фиксирует уже принятые
продуктовые решения, чтобы не начинать повторный аудит тех же экранов без новой
причины.

Повторно открываем решение только если:

- найден воспроизводимый баг;
- изменился контракт API или смысл показателя;
- появились новые реальные данные;
- пользователь явно просит изменить принятое решение.

## Общие правила

- Backend — источник истины для агрегатов, record, winrate, BYE и признака малой
  выборки.
- Клиентская сортировка помечается как сортировка только загруженных строк.
- Предупреждение о частичном списке находится вне горизонтального скролла и не
  ломает мобильную вёрстку.
- Таблицы не должны выводить колонку, смысл которой теряется без обязательного
  фильтра.
- Число предпочтительнее декоративной шкалы, если шкала не добавляет контекст.
- На мобильном экране допустим горизонтальный скролл сложной таблицы, но текст,
  фильтры и действия должны оставаться в ширине экрана.

## Главная

Экран считается проверенным.

- Без выбранных фильтров остаются только общая сводка и последние события.
- Аналитика колод и матчапов показывается только при выбранном формате.
- «Игроки с лучшими результатами» — топ-10, только на достаточной выборке.
- Полосы у доли меты и процента побед удалены: остаются точные значения.
- Колонки и кнопки выровнены; повторяющиеся и слабые обзорные блоки убраны.
- Не возвращаем метрики, которые лишь пересказывают соседнюю таблицу.

## Дейлики

Экран считается проверенным.

- Без фильтров не показывается общая аналитика, смысл которой смешивает города,
  клубы и форматы.
- При выбранном срезе остаются средняя посещаемость, рекорд посещаемости,
  динамика и самый активный клуб.
- «Обычные дни проведения» не добавляем.
- Клуб и формат скрываются из таблицы, когда уже заданы фильтром.
- Колонки с техническими подробностями списка сокращены.

## Игроки

Экран списка считается проверенным.

- Основная задача экрана — найти игрока и быстро оценить объём и результат его
  выступлений.
- Оставлены турниры, сыгранные матчи, record, процент побед и любимая колода при
  выбранном формате.
- BYE не занимает отдельную строку в списке; подробность остаётся в профиле.
- Удалён «Быстрый ориентир», который повторял первую строку таблицы и требовал
  отдельной загрузки всех игроков.
- Любимая колода скрывается без выбранного формата.
- Поддержаны серверные поля `lastTournamentDate` и `undefeatedTopsCount`.
  Первое показывается под именем, второе — отдельной колонкой. Пока production
  API их не возвращает, пустые элементы интерфейса не выводятся.
- `undefeatedTopsCount` означает число турниров, где игрок прошёл все
  запланированные раунды без поражений и ничьих. Досрочно выбывшие игроки не
  учитываются.

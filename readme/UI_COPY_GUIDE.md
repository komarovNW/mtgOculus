# Интерфейс и тексты

Этот файл фиксирует базовые правила для публичных страниц Magic Oculus.

## Вёрстка

- Проверяем экраны на ширине 360, 390, 768 и 1440 px.
- У страницы не должно быть горизонтальной прокрутки. Отдельная таблица или матрица может прокручиваться внутри своего контейнера.
- Минимальная зона нажатия для кнопок и вкладок — 44 px.
- Длинные имена и числа не должны ломать сетку.
- Светлая и тёмная темы должны иметь одинаковую структуру.

## Тексты

- Заголовок называет сущность или действие: «Колоды», «Матчапы», «Добавить турнир».
- Под заголовком — не больше одного короткого предложения.
- Не объясняем в интерфейсе, как работают API, сортировка или загрузка данных.
- Подсказку добавляем, только если без неё легко ошибиться.
- В кнопке используем действие: «Применить», «Показать ещё», «Сбросить».
- Для публичных экранов используем «Процент побед». «Винрейт» допустим только в компактном профессиональном контексте.
- BYE не называем сыгранным матчем и показываем отдельно.
- «Мало данных» понятнее, чем «малая выборка».

## Проверка экрана

Перед готовностью экрана проверяем обычное состояние, загрузку, ошибку и пустой результат. Для каждого состояния нужно убедиться, что:

- все действия доступны с клавиатуры;
- фокус виден;
- длинные названия не обрезаны без возможности узнать полное;
- светлая и тёмная темы остаются читаемыми.
